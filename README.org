#+TITLE: Dots
#+DESCRIPTION: Personal dotfiles and machine setup automation

* Overview

This repository manages personal dotfiles via [[https://www.gnu.org/software/stow/][GNU Stow]] and provides
modular install scripts for setting up a new machine.

Each top-level directory (except =install/=) is a stow package that gets
symlinked into =~/=.

* Prerequisites
- git
- GPG private key for unix pass configuration

* Usage

#+begin_src sh
# Show available modules
./install.sh

# Run all modules
./install.sh all

# Run specific modules
./install.sh packages gpg git stow

# Just restow dotfiles
./install/stow.sh

# Unstow dotfiles
./install/stow.sh --unstow
#+end_src

* Modules

| Module       | Description                                     |
|--------------+-------------------------------------------------|
| =packages=   | Install system packages from OS-specific list   |
| =gpg=        | Import GPG keys and initialize password store   |
| =git=        | Configure global git settings                   |
| =emacs=      | Build Emacs from source                         |
| =doom=       | Install and configure Doom Emacs                |
| =systemd=    | Enable user systemd services (Linux only)       |
| =browserpass= | Build and install browserpass-native            |
| =hyprpm=     | Set up Hyprland plugins                         |
| =stow=       | Symlink dotfiles into =~/= via GNU Stow        |

When running =./install.sh all=, modules execute in the order listed above.

* Stow Packages

Every top-level directory except =install/= is treated as a stow package.
Adding a new directory automatically includes it — no configuration needed.

The =stow= module backs up any existing (non-symlink) directories that would
conflict before stowing.

* Package Lists

OS-specific package lists live in =install/packages/=. The file is selected
automatically based on the detected OS.

#+begin_example
install/packages/
├── linux-debian    # apt
├── linux-arch      # pacman
├── macos           # brew
└── windows         # winget IDs, used by install/windows/install.ps1
#+end_example

Each line is a package name, with an optional second column for a non-default
package manager:

#+begin_src text
ripgrep
tmux
some-aur-package yay
tree-sitter-cli npm
#+end_src

* Windows

Windows has no stow; =install/windows/install.ps1= installs packages and
copies the few configs used there instead.

** Setup

Run in PowerShell (not cmd.exe):

#+begin_src powershell
# Git first, to clone this repo (open a new terminal afterwards so it is on PATH)
winget install --id Git.Git --exact
git clone https://github.com/logexp1/dots.git $HOME\dots
cd $HOME\dots

# Once per user: allow local scripts, so no -ExecutionPolicy Bypass is needed
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# Show available modules / run all / run specific ones
.\install\windows\install.ps1
.\install\windows\install.ps1 all
.\install\windows\install.ps1 gpg passmenu
#+end_src

** Modules

| Module      | Description                                                                   |
|-------------+-------------------------------------------------------------------------------|
| =packages=  | Install winget packages from =install/packages/windows=                       |
| =gpg=       | gpg-agent cache config, import =%OneDrive%\privkey.asc=, clone password store |
| =passmenu=  | Install pass-winmenu (Ctrl+Alt+P) with a startup shortcut                     |
| =tridactyl= | Install the Tridactyl native messenger, copy the rc to =~\.tridactylrc=       |

The Tridactyl extension itself arrives through Firefox account sync. The rc
is a copy, not a link, so re-run =install.ps1 tridactyl= after editing
=browsing/.tridactylrc=.

** Manual steps

- PowerToys Keyboard Manager (installed by =packages=): remap
  =Ctrl (Left)= → =Alt (Left)=, =Alt (Left)= → =Ctrl (Left)= and
  =Caps Lock= → =Win (Left)=, matching the Hyprland =kb_options=. Pick the
  =Left= keys explicitly so the right-hand 한/영 and 한자 keys stay as they are.
